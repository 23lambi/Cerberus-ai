Get Cerberus

Install from your terminal with Git and Python 3.14.

Install from your terminal

Install Git and Python 3.14 first. Choose your system, then copy the commands into a terminal. Cerberus opens when you run the last command.

# 1. Download the code
git clone https://github.com/23lambi/Cerberus-ai.git
cd Cerberus-ai

# 2. Install what it needs
python3.14 -m venv venv
venv/bin/python -m pip install -r requirements.txt

# 3. Start Cerberus
venv/bin/python desktop.py

Want it in your app menu? Run sh install-desktop.sh once.

# 1. Download the code
git clone https://github.com/23lambi/Cerberus-ai.git
cd Cerberus-ai

# 2. Install what it needs
py -3.14 -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt

# 3. Start Cerberus
.\venv\Scripts\python.exe desktop.py

Want it in your Start menu? Run powershell -ExecutionPolicy Bypass -File install-desktop.ps1 once.

On first launch, a short setup helps you choose your AI and model.

To update later: close Cerberus, run git pull, then repeat the pip install command in step 2.

Questions

Is it free?

Yes. Cerberus is free and open source under the Apache 2.0 license. Cloud AI services you connect may charge for their use.

Does my data leave my computer?

Not with a local engine: chats and documents stay on your computer. With a cloud engine, your messages and the context you share go to that service. Web search contacts your search service and the pages it opens.

What computer do I need?

A 64-bit Windows, macOS or Linux computer. For local AI, 8 GB of memory runs small models; 16 GB or more is more comfortable. Setup suggests a model that fits.

Which models can I use?

Any chat model your engine offers: Llama, Qwen, Gemma, Mistral and many more. Cerberus reads reasoning and tool calls in all the common formats.

How do I report a bug or suggest an idea?

Open an issue on GitHub. In the app, Settings → Help → Copy diagnostics collects the details a bug report needs.
