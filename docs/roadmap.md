# Roadmap

[← README](../README.md)

Cerberus is in active development. These are the next goals, in order, not
release commitments.

1. **Connection profiles:** each API key stays with its own provider and address.
2. **Edit and branch:** change a sent message and keep both versions.
3. **Developer mode:** custom assistants and advanced model settings, hidden
   until you switch it on.
4. **MCP servers:** connect extra tools, in developer mode.
5. **Recovery:** restore a backup from Settings.
6. **Clearer download problems:** say what went wrong and what to do next.

Each goal, with what "done" means: [Next goals](development/next-goals.md).

Current features are described in the [README](../README.md) and
[user guide](guide.md). Suggest improvements through
[GitHub issues](https://github.com/23lambi/Cerberus-ai/issues/new/choose).
