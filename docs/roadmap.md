# Roadmap

[← README](../README.md)

Cerberus is in active development. These are areas for improvement, not release
commitments.

1. **First release:** complete native build checks and verify clean installs and updates.
2. **Connection profiles:** isolate API keys by provider/address and simplify switching.
3. **Model setup:** clearer Download/Use/Start actions, memory-fit estimates and useful errors.
4. **Recovery:** accessible backup/restore and a defined update rollback strategy.
5. **Optional capabilities:** local dictation, sandbox previews, then selected MCP integrations.

See the [Atomic Chat comparison](development/atomic-chat-review.md) for source
references, current gaps, and acceptance criteria. These ideas are not all implemented.

Current features are described in the [README](../README.md) and
[user guide](guide.md). Suggest improvements through
[GitHub issues](https://github.com/23lambi/Cerberus-ai/issues/new/choose).
