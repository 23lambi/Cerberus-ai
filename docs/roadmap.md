# Roadmap

[← README](../README.md)

Cerberus is in active development. These are areas for improvement, not release
commitments.

- **Desktop experience:** clearer navigation, accessible controls, and better
  onboarding across supported platforms.
- **Local engines:** broader real-model testing and smoother model setup.
- **Documents:** easier editing, retrieval, and source inspection.
- **Research:** more reliable planning, citations, and progress feedback.
- **Distribution:** simpler installation and tested macOS and Windows workflows.

Current features are described in the [README](../README.md) and
[user guide](guide.md). Suggest improvements through
[GitHub issues](https://github.com/23lambi/Cerberus-ai/issues/new/choose).
